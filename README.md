# QR Code Generator

A customizable QR Code Generator built using HTML, CSS and JavaScript.

## Features

- Generate QR codes from plain text
- Generate QR codes for URLs
- Generate email QR codes
- Generate phone number QR codes
- Generate Wi-Fi QR codes
- Customize QR code size
- Customize foreground and background colors
- Choose error correction levels
- Choose QR presets
- Adjust QR code margin
- Real-time QR code preview
- Download QR codes as PNG
- Recent QR codes stored using localStorage
- Click recent QR codes to load them again
- Input validation
- Scan reliability warning for low-contrast colors
- Responsive design for desktop and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- QRCode.js
- Browser Local Storage

## How to Use

1. Select the type of QR code you want to create.
2. Enter the required information.
3. Customize the QR code using the available options.
4. Preview the QR code in real time.
5. Click **Download QR** to save it as a PNG image.
